Kaluach Help

Personal Events

Kaluach can track recurring Hebrew dates and one-time events, and can optionally add a separate civil-date recurrence.

Create an event with the + button or open the Events window to see and filter all tracked events.

Besides its name, an event can have a short Description — for example a Hebrew name, a relationship, or another note. It appears under the event in the selected day’s details and in the Events window.

Event types

  • Azkara or yahrzeit: Enter the Hebrew date of death and choose the rite, Sephardi or Ashkenazi; the rite is saved with the event. A plain-Adar date follows the custom you select for a leap year. For the first year, you may base the date on the burial instead: set how many days after the death the burial took place (1 to 30) with the stepper, which shows the resulting Hebrew and civil date. The first azkara is then kept on the burial date, and every later one on the date of death.
  • Birthday or anniversary: Enter the Hebrew date. Kaluach treats a plain-Adar birthday as Adar II and displays a reminder that opinions differ. A wedding anniversary can use its own icon.
  • One-time event: Choose one Hebrew date with no recurrence.
  • Bar or Bat Mitzvah: A birthday can calculate the upcoming date according to the gender entered.

Every event needs a name. A date of death or birth can’t be in the future — the one exception is a Hebrew date that began at sunset this evening. If something can’t be saved, a message explains why and the form stays open.

Optional civil recurrence

A recurring event may also recur on a fixed Gregorian date. Because a Hebrew day touches two civil dates, choose either the earlier or later date. This is an additional recurrence; it does not change the event’s Hebrew recurrence.

Reminders

Check Remind me to be reminded the day before each occurrence, at the event reminder time set in Settings. See Alarms and reminders.

Finding and managing events

The Events window lists every event by name. Narrow it with the type checkboxes, or type in Search to find events by name or description.

Use an event row’s menu or right-click it to go to its original date, burial date when present, next Hebrew or enabled civil occurrence, or Bar/Bat Mitzvah date. The same menu offers Edit and Delete. After you go to a date, save an edit, or confirm a deletion, the Events window closes so the calendar is in view. Events appear in the calendar and at the top of the selected day’s details, with their type.

On your other devices

When you are signed into iCloud, your events appear on your other Macs and in iKaluach on your iPhone, and stay the same everywhere: an event added, changed, or deleted on one device follows on the others, usually within a minute. Nothing needs to be set up. Settings shows whether syncing is on; if iCloud is off for Kaluach, your events stay on this Mac.

Export and import

File → Export Events… saves your events in a Kaluach events file — a backup, and the way to share events with family or a community, or to move them to Kaluach on Android or Windows. First it lists your events, all checked: uncheck the ones you don’t want. The type filters and the search narrow the list, and Select All and Select None act on the events shown — so to send only one family, search for its name and choose Select All. The count shows how many are chosen; Export… saves just those.

File → Import Events… reads such a file and lists its events the same way: new ones are checked, and events you already have are dimmed and marked “Already in Kaluach”. Import adds only the checked ones; importing never deletes or changes anything you have.

Import Events also reads the events file of the old Windows Kaluach3 (events.ini): birthdays, anniversaries and azkarot come in with their Hebrew date, and an event that also had its civil date keeps that too.

File → Export to Calendar (.ics)… lists your events the same way, then saves the next ten years of the checked ones as an .ics file for Apple Calendar or another calendar app — every occurrence as an all-day entry, with its Hebrew date and description. This is one way only: Kaluach doesn’t read .ics files back, so keep the events file as your backup.
