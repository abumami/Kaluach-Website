Kaluach Help

Troubleshooting

Solutions to common problems.

Use My Location does not respond

Check System Settings → Privacy & Security → Location Services and confirm that location access is enabled for Kaluach.

Place suggestions do not appear

Suggestions require an internet connection. With a working connection, press Return to try a direct search.

A location is classified incorrectly

Israel-or-diaspora classification can depend on how the place is identified by map data. Use the Country control in Location Settings to override it for that saved place, and record the exact place name so its automatic handling can be reviewed. This does not alter the separately resolved time zone.

Alarms or reminders don’t appear

Check System Settings → Notifications → Kaluach, and any Focus that may be silencing it. Nothing is sent on Shabbat or Yom Tov, and alarms are scheduled only up to two weeks ahead, refreshed each time Kaluach is opened.

Events don’t appear on my other device

Both devices need to be signed into the same Apple Account with iCloud, and iCloud must be on for Kaluach (System Settings → your name → iCloud on the Mac; Settings → your name → iCloud on the iPhone). The line at the bottom of Settings shows whether Kaluach is syncing. Changes usually arrive within a minute; bringing Kaluach to the front checks at once.

A displayed time is consistently one hour wrong

Confirm the location and time zone first. If its daylight-saving rule is still incorrect, change that location’s Daylight Saving setting from Automatic to the required override.
