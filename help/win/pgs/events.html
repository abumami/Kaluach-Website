Kaluach Help

Personal Events

Kaluach can track recurring Hebrew dates and one-time events, and can optionally add a separate civil-date recurrence.

Create an event with the + button in the toolbar, or open the Events list (the button beside it) to see and filter all tracked events.

Besides its name, an event can have a short Description — for example a Hebrew name, a relationship, or another note. It appears under the event in the selected day’s details and in the Events list.

Event types

  • Azkara or yahrzeit: Enter the Hebrew date of death and choose the rite, Sephardi or Ashkenazi; the rite is saved with the event. A plain-Adar date follows the custom you select for a leap year. For the first year, you may base the date on the burial instead: set how many days after the death the burial took place (1 to 30), which shows the resulting Hebrew and civil date. The first azkara is then kept on the burial date, and every later one on the date of death.
  • Birthday or anniversary: Enter the Hebrew date. Kaluach treats a plain-Adar birthday as Adar II and displays a reminder that opinions differ. A wedding anniversary can use its own icon.
  • One-time event: Choose one Hebrew date with no recurrence.
  • Bar or Bat Mitzvah: A birthday can calculate the upcoming date according to the gender entered.

Every event needs a name. A date of death or birth can’t be in the future — the one exception is a Hebrew date that began at sunset this evening. If something can’t be saved, a message explains why and the form stays open.

Optional civil recurrence

A recurring event may also recur on a fixed civil date. Because a Hebrew day touches two civil dates, choose either the earlier or later date. This is an additional recurrence; it does not change the event’s Hebrew recurrence.

Reminders

Check Remind me to be reminded the day before each occurrence, at the reminder time set in Settings. See Reminders.

Finding and managing events

The Events list shows every event by name. Narrow it with the type checkboxes, or type in Search to find events by name or description.

Click an event for its actions: go to its original date, burial date when present, next Hebrew or enabled civil occurrence, or Bar/Bat Mitzvah date; Edit Event…; and Delete Event. After you go to a date, save an edit, or confirm a deletion, the Events list closes so the calendar is in view. Events appear in the calendar and at the top of the selected day’s details, with their type.

Your events are kept on this computer.

Export and import

In the Events list, the ⋯ button holds Export Events… and Import Events…. Both first show a list of events to choose from, with the type checkboxes, Search, Select All and Select None (which act on the events shown), and how many are selected.

  • Export Events… starts with every event checked; uncheck the ones to leave out, then Export… saves the checked ones in a Kaluach events file — a backup, and the way to move events to Kaluach on the Mac, the iPhone or Android.
  • Import Events… reads a Kaluach events file and lists its events: new ones are checked, and ones already in Kaluach are dimmed and marked “Already in Kaluach”. Import adds the checked ones. Import never deletes or changes your events.
